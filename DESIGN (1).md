## Marca e Estilo

Este sistema de design é construído sobre os pilares da precisão científica, desempenho de elite e energia tecnológica. Com a transição para uma variante **Vibrant**, a personalidade da marca evoluiu de uma precisão puramente clínica para uma estética de alta energia e saturação, evocando interfaces de comando avançadas e fluxos de dados dinâmicos. O objetivo é criar uma resposta emocional de prontidão tecnológica e agilidade digital.

O estilo visual segue uma estética **Corporate / Modern** com uma paleta **High-Contrast / Bold**. A interface é predominantemente escura para reduzir a fadiga visual, mas agora utiliza uma tríade de tons ciano e azuis elétricos para criar uma hierarquia visual mais rica e vibrante, garantindo que a navegação seja intuitiva e visualmente estimulante.

## Cores

A paleta foi expandida para uma gama vibrante de azuis tecnológicos e cianos luminescentes, abandonando os tons neutros frios em favor de uma profundidade mais saturada.

- **Primary Cyan (#00F1FE):** A cor de destaque principal, usada para as ações mais importantes e estados ativos críticos. Representa a "ignição" do sistema.
- **Electric Secondary (#00E0FE):** Um tom complementar que adiciona vibração a elementos de interface secundários, criando um gradiente visual de importância.
- **Deep Azure Tertiary (#0580D3):** Utilizada para acentos profundos e componentes que requerem distinção sem a urgência do ciano primário.
- **Teal-Grey Neutral (#497F8A):** Substitui os cinzas tradicionais por um tom de base que harmoniza com a paleta ciano, mantendo a coesão cromática mesmo em elementos de suporte e tipografia auxiliar.

## Tipografia

Este sistema de design utiliza exclusivamente a fonte **Sora**. Sua natureza geométrica e glifos nítidos reforçam a estética de precisão industrial e clareza técnica.

- **Headlines:** Devem exibir uma estrutura forte e confiante. O rastreamento (letter-spacing) ligeiramente apertado em tamanhos maiores aumenta a sensação de densidade e importância.
- **Body:** Focado na legibilidade máxima em telas de alta densidade de pixels. O peso regular garante clareza sem distrair dos dados.
- **Labels:** Frequentemente apresentados em maiúsculas com espaçamento entre letras aumentado para criar uma distinção visual clara entre conteúdo narrativo e dados metadados/funcionais.

## Layout e Espaçamento

O sistema de layout é baseado em uma grade fluida de 12 colunas para desktop, adaptando-se para 4 colunas em dispositivos móveis. A escala de espaçamento segue um ritmo rigoroso de **8px**, garantindo que todos os elementos estejam alinhados matematicamente.

- **Desktop (1440px+):** Layout de 12 colunas com margens amplas de 40px para permitir que o conteúdo "respire" em meio à escuridão do fundo.
- **Tablet (768px - 1439px):** Margens de 32px e gutters de 24px.
- **Mobile (< 767px):** Colapso para uma única coluna funcional com margens de 20px, priorizando a densidade de informações e o alcance do polegar.

O uso do espaço negativo é estratégico: ele deve separar blocos de dados complexos para evitar a sobrecarga cognitiva, mantendo o foco na energia ciano das ações principais.

## Elevação e Profundidade

A profundidade é construída através de camadas tonais saturadas e luminescência estratégica, reforçando a estética "vibrant".

1.  **Nível Base (L0):** Deep Obsidian - O plano de fundo infinito.
2.  **Nível de Superfície (L1):** Teal-Grey Neutral (#497F8A) com opacidades variadas (8-15%) para definir contêineres e áreas de conteúdo.
3.  **Nível de Destaque (L2):** Bordas finas de 1px utilizando cores secundárias ou terciárias em baixa opacidade para definir volume sem sombras pesadas.
4.  **Luminescência (Vibrant Glow):** Elementos em foco ou ativos (como botões primários) emitem um brilho suave de Primary Cyan. O efeito de "Backdrop Blur" é utilizado em modais e menus flutuantes para manter a hierarquia sobre o conteúdo dinâmico.

## Formas

A linguagem de formas equilibra o rigor técnico com o conforto moderno. O sistema utiliza uma arredondamento de nível **2 (Rounded)**.

- **Componentes Padrão:** Botões, campos de entrada e chips possuem um raio de 0.5rem (8px).
- **Cards e Grandes Contêineres:** Utilizam o `rounded-lg` (16px) para suavizar a interface industrial.
- **Elementos de Estado:** Pequenos indicadores e notificações podem usar `rounded-xl` para uma aparência mais amigável em situações de alerta.

A geometria deve ser consistente: se um elemento é arredondado, todos os seus filhos e estados relacionados devem seguir a mesma lógica matemática.

## Componentes

### Botões (Buttons)
- **Primário:** Fundo Primary Cyan (#00F1FE) com texto em fundo escuro. Em estado *hover*, deve apresentar um brilho externo intenso.
- **Secundário:** Borda e texto em Electric Secondary (#00E0FE). Transmite uma ação importante, mas não crítica.
- **Terciário:** Estilo fantasma (ghost) com acentos em Deep Azure (#0580D3).

### Campos de Entrada (Input Fields)
- Fundo em Teal-Grey neutro escuro. Borda de 1px que muda para Primary Cyan quando em foco. O cursor deve pulsar na cor primária.

### Chips e Tags
- Pequenos, com tipografia `label-sm`. Usados para categorização de dados técnicos. Fundo neutro saturado com bordas sutis em Deep Azure.

### Cards
- Superfícies planas com bordas de 1px em Teal-Grey a 20% de opacidade. O cabeçalho do card pode ter uma linha de acento horizontal de 2px em Electric Secondary para indicar importância.

### Listas de Dados
- Linhas separadas por divisores de 1px em baixa opacidade. Ícones de status devem usar o Primary Cyan para "Online/Ativo", Electric Secondary para "Processando" e Deep Azure para estados de repouso.

### Indicadores de Pulsação (Pulse Indicators)
- Componente exclusivo para monitoramento em tempo real: um pequeno círculo Primary Cyan com uma animação de expansão de opacidade (ripple effect) para denotar atividade constante.
